# Security Policy for DocDen

## Supported Versions

Security fixes and improvements are provided for active versions of DocDen:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |

## Reporting a Vulnerability

As a privacy and security-oriented application handling encrypted documents, we take security matters with the utmost seriousness. If you discover a security vulnerability in DocDen, please report it privately rather than opening a public issue.

### How to Report
- **Email:** Send full details directly to developer Riyuk Saha at [RiyukSaha@gmail.com](mailto:RiyukSaha@gmail.com) with subject `[SECURITY] DocDen Vulnerability Report`.
- Alternatively, submit a private security advisory via GitHub.
- **Please include:**
  - Description of the vulnerability (e.g. cryptographic, storage leak, biometric bypass)
  - Affected Android OS versions and device models
  - Reproduction steps or proof-of-concept
  - Potential security impact assessment

### Response Timeline
- **Initial acknowledgment:** Within 24–48 hours.
- **Assessment & mitigation plan:** Within 3–5 business days.
- **Security Release:** Fast-tracked in the next point release.

Thank you for helping keep DocDen secure for all users.
